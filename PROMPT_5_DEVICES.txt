0. BALASAN KHUSUS UNTUK PC NAUFAL (pc-naufal) - Yang Sedang Menunggu
================================================================================

1. Tolong install Tailscale otomatis di PC ini sekarang:
   - Jika Windows: jalankan perintah "winget install Tailscale.Tailscale --silent --accept-package-agreements --accept-source-agreements"
   - Jika Linux: jalankan perintah "curl -fsSL https://tailscale.com/install.sh | sh"
   - Setelah terpasang, jalankan "tailscale up" dan berikan tautan URL loginnya agar saya bisa login dengan akun Google maraazn069@...

2. IP Tailscale VPS Control Plane adalah: 100.66.49.13

3. Lanjutkan instalasi agy-fleet dari repo publik https://github.com/ibrstore/agy-fleet.git dengan parameter:
   - NODE_ID: "pc-naufal"
   - NATS_URL: "nats://100.66.49.13:4222"
   - Daftarkan sebagai background service.

1. PROMPT UNTUK PC DIBA (pc-diba)
================================================================================

Tolong lakukan instalasi dan konfigurasi lengkap agy-fleet untuk node "pc-diba":

1. Pasang & Jalankan Tailscale:
   - Jika belum ada, install otomatis:
     • Windows: winget install Tailscale.Tailscale --silent --accept-package-agreements --accept-source-agreements
     • Linux: curl -fsSL https://tailscale.com/install.sh | sh
   - Jalankan "tailscale up" dan tampilkan link loginnya agar saya login ke akun Google (maraazn069@...).

2. Clone Repository agy-fleet:
   git clone https://github.com/ibrstore/agy-fleet.git ~/agy-fleet

3. Siapkan Environment:
   cd ~/agy-fleet && python -m venv .venv && pip install -e .

4. Konfigurasi ~/.agy-fleet/daemon.json:
   {
     "node_id": "pc-diba",
     "device_type": "pc",
     "nats_url": "nats://100.66.49.13:4222"
   }

5. Pasang Background Service:
   - Windows (PowerShell Admin): .\scripts\install_service_windows.ps1 -NodeId "pc-diba"
   - Linux: ./scripts/install_service_linux.sh daemon pc-diba
