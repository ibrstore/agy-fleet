================================================================================
           PROMPT ONBOARDING AGY-FLEET (5 PERANGKAT KLIEN)
================================================================================

Repository Resmi: https://github.com/ibrstore/agy-fleet.git

CATATAN SEBELUM EKSEKUSI:
1. Pastikan VPS Anda sudah terhubung ke Tailscale dengan membuka link:
   👉 https://login.tailscale.com/a/g1fc45b842017dbfd
   Setelah login, cek IP Tailscale VPS Anda (misal: 100.x.y.z).
2. Di setiap prompt di bawah, cukup ganti <IP_TAILSCALE_VPS> dengan IP Tailscale VPS Anda.
3. Salin masing-masing blok teks ke Antigravity CLI (agy) di perangkat terkait.

================================================================================
1. PROMPT UNTUK PC NAUFAL (pc-naufal)
================================================================================

Kamu bertindak sebagai Node Installer untuk agy-fleet di perangkat pc-naufal.
Tugasmu adalah menyiapkan agy-daemon di mesin ini agar terhubung ke Control Plane VPS secara otomatis sebagai background service.

Parameter Node ini:
- NODE_ID: "pc-naufal"
- DEVICE_TYPE: "pc"
- REPO_URL: "https://github.com/ibrstore/agy-fleet.git"
- NATS_URL: "nats://<IP_TAILSCALE_VPS>:4222"

Instruksi Eksekusi:
1. Pastikan Tailscale aktif di PC ini dan bisa terhubung ke VPS.
2. Clone repository agy-fleet ke direktori lokal:
   - Jika Windows: git clone https://github.com/ibrstore/agy-fleet.git $HOME\agy-fleet
   - Jika Linux: git clone https://github.com/ibrstore/agy-fleet.git ~/agy-fleet
3. Masuk ke folder agy-fleet, buat virtualenv Python 3.11+, lalu install dependensi:
   python -m venv .venv
   pip install -e .
4. Buat file konfigurasi ~/.agy-fleet/daemon.json dengan isi:
   {
     "node_id": "pc-naufal",
     "device_type": "pc",
     "nats_url": "nats://<IP_TAILSCALE_VPS>:4222"
   }
5. Pasang sebagai background service otomatis:
   - Jika Windows (PowerShell Run as Admin): .\scripts\install_service_windows.ps1 -NodeId "pc-naufal"
   - Jika Linux: ./scripts/install_service_linux.sh daemon pc-naufal
6. Pastikan service aktif dan mengirim heartbeat setiap 5 detik ke NATS.
